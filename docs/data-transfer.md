# 本地保存与 EEGQC 上传

1. 在本地 `data/sub-{SUB_ID}/ses-{YYMMDD##}/` 完成本次会话。停止刺激与设备接收，关闭各模态文件，再写入真实结束时间、各 run 状态及停止原因。保留可读取的中断和低质量记录。
2. 按 [多模态数据存放规范](../data/README.md) 核对被试、范式、会话 UUID 和各 run 的文件前缀。检查信号样本数、通道顺序和单位，核对 EEG 事件零点、视频事件及同步说明。只为实际采集的模态准备文件。
3. 封存完整会话。将包含 `session.json` 和各模态目录的会话交给 EEGQC，目录或 ZIP 均保留相对路径。保留本地原始文件。当前模拟 CSV/JSON 输出的格式见 [模拟数据格式](data-format.md)。
4. 在 EEGQC 中确认被试和范式，核对识别到的 run 数量、各段时长及评分结果，再上传并提交入库。由 EEGQC 保存报告和数据库回执。
5. 上传重试使用同一份已封存的会话及原 `session_id`。文件上传成功而数据库回写失败时，在 EEGQC 中重试入库，以数据库回执确认完成。
